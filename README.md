# Kulaklığa Dolanan Kablonun Uluslararası Deniz Hukuku Mahkemesi

> *Kablo çözülmez. Kablo tescil edilir.*

Bu yazılım, cepte, çantada veya masa çekmecesinde kendi kendine devletleşen kulaklık kablolarını **1982 Birleşmiş Milletler Deniz Hukuku Sözleşmesi** (hayali ek protokol: ISO-YOK-1982) çerçevesinde yargılar.

Sol kulaklık kıyı devletidir.  
Sağ kulaklık açık denizdir.  
Jak, kara sularının dış sınırıdır.  
Düğüm, kıta sahanlığının doğal uzantısıdır.  
Çözme teşebbüsü, zararsız geçiş değildir.

## Kuruluş Gerekçesi

Bilimsel olarak kanıtlanmıştır ki bir kulaklık kablosu, gözden kaybolduğu andan itibaren en az üç egemenlik iddiası üretir. Bu mahkeme o iddiaları kayda geçer, hüküm kurar ve kabloyu yine dolaşık bırakır. Çünkü adalet, düğümün kendisidir.

## Kuruluş

```bash
python3 mahkeme.py
```

Bağımlılık yoktur. Python 3 yeterlidir. Deniz yoktur. Kablo vardır.

## Yetki

Mahkeme şu konularda nihaidir:

- münhasır ekonomik bölge (cep cebi)
- tarihi körfez (kulaklık kıvrımı)
- yapay ada inşası (bilinçli olmayan düğüm)
- düz esas hat çizme (kabloyu düz tutma hayali)

## Yasal Uyarı

Bu yazılım hiçbir gerçek devleti, anlaşmayı veya kulaklık markasını temsil etmez. Kararlar bağlayıcı değildir; kablo zaten bağlıdır.
